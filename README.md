# 麦门信徒的点餐搭子 🍔

一个 **麦当劳像素风点餐网站应用**，采用「麦门信徒·五派系」的世界观设定，复古星露谷（Stardew Valley）16bit 像素 RPG 美学。

> 🔗 在线体验：https://maimai-order.app.workbuddy.host/?sharecode=KJCIFL2GMJ

## ✨ 项目简介

用户进入后先选择所在城市与门店、确定用餐人数，再选择自己的「派系」（角色人设），系统根据派系偏好 + 预算 + 优惠券 + 真实麦当劳菜单数据，推荐对应的餐品组合。

**视觉风格**：低饱和暖木质感配色、米黄奶油底、深棕描边立体像素块、像素云朵 / 砖块 / 金币点缀，整体治愈烟火气。

**技术形态**：纯单文件 HTML（内联 CSS + 原生 JS，无框架、无构建），数据通过麦当劳 MCP 实时获取 + 云端服务持久化。

## 🧭 五大派系

| 派系 | 定位 | 推荐逻辑 |
|---|---|---|
| 🌍 地球NPC · 务实信徒 | 预算优先，稳定划算 | 只看预算 + 优惠满减，不看口味 |
| 💪 健身达人 · 自律信徒 | 控卡 / 增肌 | 减脂 / 增肌双模式 + 营养达标检测 |
| 🍔 大胃食客 · 饱腹信徒 | 饭量派系 | 高饱腹优先 + 干饭目标 / 段位 / 徽章 |
| 🌸 寻味旅人 · 情绪信徒 | 氛围派系 | 6 档情绪 → 专属套餐推荐 |
| 🎁 随缘行者 · 盲盒信徒 | 交给命运 | 扭蛋机随机推荐（5 主题） |

## 🚀 核心功能

- **城市 / 门店选择**：接入麦当劳 MCP 真实门店数据（8 城 40 家）
- **单人点餐**：自由点单 + 按预算推荐套餐 + 底部折叠导航条
- **多人拼单**：选人数 + 全桌忌口 + 需求解析 + AA 账单拆分
- **优惠券体系**：满减 / 1+1 随心配 / 甜品第二份半价，自动匹配
- **云端持久化**：登录后购物车 / 订单 / 心愿单同步（WorkBuddy Cloud Service）
- **彩蛋玩法**：盲盒扭蛋机、欧气分享卡、麦门赐福、段位徽章、心愿卡

- **前端**：原生 HTML + CSS + JavaScript（单文件，无框架）
- **数据源**：麦当劳 MCP（`mcd-mcp` 实时接口）
- **后端**：WorkBuddy Cloud Service（云数据库 + RLS + 用户认证）
